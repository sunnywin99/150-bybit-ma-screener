Bybit USDT 永續合約 MA150 上揚篩選器

掃描 Bybit 所有 USDT 本位（linear）永續合約的日K線，先看一件事： 日K計算出的 150 日均線（MA150），依你選的條件篩選——可以選「至少連續 N 天上揚」（上揚天數不少於 N 天，可能更多）， 也可以選「剛好第 N 天上揚」（從最近一根已收盤日K數起，MA150 剛好連續漲了 N 天，再往前一天就沒漲了）。 不看 MA50、MA200，符合的全部列成一份清單。 再從這份清單裡，額外挑出過去 3 天累積漲幅超過 10% 的商品，列在下方的第二份清單。 資料在你按下「開始掃描」時，即時從 Bybit 公開 API 抓取，不會儲存在任何伺服器上。
